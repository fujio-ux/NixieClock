# NixieClock

Smart Weather Clock（SD Pro、[JUZIPi-tech/SD_PRO](https://github.com/JUZIPi-tech/SD_PRO)）用の自作ファームウェアです。
画面をニキシー管の時計と、ニュースが流れる電光掲示板に変えます。

## まずは最初の設定（Wi-Fi）

スマホ 1 台あれば、5 分ほどで終わります。
まだこのファームを時計に書き込んでいない場合は、先に下の「[書き込み方](#書き込み方)」を済ませてください。

### 1. 時計の電源を入れる

30 秒ほど待つと、時計が自分で Wi-Fi「**NixieClock-Setup**」を出し、画面の上に次の案内が出ます。

<img src="docs/images/01_clock.png" width="240" alt="設定用 Wi-Fi を出しているときの時計の画面（イメージ）">

（画面はイメージです。ニキシー管は、時刻が分かるまで消えたままです）

### 2. スマホを「NixieClock-Setup」につなぐ

スマホの「設定」→「Wi-Fi」で **NixieClock-Setup** を選び、パスワード **`password`** を入れます。

- つなぐと、設定画面が自動で開きます。
- 開かないときは、ブラウザで **`http://192.168.4.1/wifi`** を開いてください。
- 「インターネットに接続されていません」と出ても、そのままつないでおいてください（時計の Wi-Fi はインターネットにつながっていないためです）。

### 3. 家の Wi-Fi を選んで保存する

<img src="docs/images/02_wifi.png" width="360" alt="Wi-Fi 設定の画面">

1. 「つなぐ Wi-Fi」の一覧から、家の Wi-Fi を選びます。名前が下の「名前（SSID）」に入ります。
   一覧に無いときは、名前を直接入れてください（2.4GHz の Wi-Fi だけに対応しています。5GHz の Wi-Fi にはつながりません）。
2. 「パスワード」に、家の Wi-Fi のパスワードを入れます。
3. 「**保存してつなぎ直す**」を押します。

<img src="docs/images/03_saved.png" width="360" alt="保存したあとの画面">

### 4. 時計がつながったことを確かめる

時計が再起動して家の Wi-Fi につなぐと、ニキシー管に時刻が出て、画面の一番上に時計の **IP アドレス**（例：`IP 192.168.1.23`）が出ます。
スマホも家の Wi-Fi に戻してください。

うまくつながらないときは、30 秒ほどでまた「NixieClock-Setup」が出るので、2 からやり直してください。

### パスワードについて

| パスワード | 初期値 | 変えられるか |
|---|---|---|
| 設定用 Wi-Fi「NixieClock-Setup」 | `password` | 変えられない（だれでも設定し直せるように固定） |
| Wi-Fi 設定・ファーム更新（ユーザー `admin`） | `password` | 設定画面の「Wi-Fi 設定のパスワードを変える」で変えられる（8 文字以上） |

- 初期値の `password` はだれでも知っているので、**家の Wi-Fi につないだあとで変えることをおすすめします**。
- 「NixieClock-Setup」から開いた設定画面では、Wi-Fi 設定のパスワードを聞きません。人から譲り受けた時計でも、前の持ち主のパスワードを知らずに設定し直せます。
  その代わり、時計が「NixieClock-Setup」を出している間は、近くにいる人も接続先を変えられます。
- 家の Wi-Fi から設定画面を開いたときは、Wi-Fi 設定のパスワードが必要です。
- 家の Wi-Fi が一時的に切れて「NixieClock-Setup」になっても、スマホがつながっていなければ 3 分ごとに家の Wi-Fi を試し、つながれば自動で戻ります。

## 使い方（設定画面）

家の Wi-Fi につないだスマホやパソコンで、ブラウザから `http://<時計のIP>/` を開くと、状態と設定が出ます。

<img src="docs/images/04_status.png" width="360" alt="状態と設定の画面">

| 設定 | 内容 |
|------|------|
| ニュース | 政府広報オンライン（新着 5 件）／地震（気象庁の情報から、震度 1 以上の直近 3 回） |
| 向き | 0〜3（画面の回転） |
| バックライト反転 | 0／1（画面が暗いままなら切り替える。この機種は 1） |
| 明るさ・夜の明るさ | 0〜100 |
| 夜の時間帯 | 何時から何時まで暗くするか |
| 流れる速さ | 電光掲示板が 1 ドット進む間隔（ミリ秒） |

設定は「保存」を押すとすぐに変わります（パスワードは不要）。
ほかに「数字を回す」「ニュースを取り直す」「Wi-Fi 設定」「ファーム更新」「再起動」があります（ファーム更新と再起動はパスワードが必要）。

## できること

- **ニキシー管 8 本で `時:分:秒`**。毎分 0 秒に全部の数字がランダムに回り、左から順に止まります（ダイバージェンスメーター風）
- **上段に時計の IP アドレス**、その下に**日付**：「10月5日(月)」、祝日は「11月23日(勤労感謝の日)」のように祝日名
- **下段に LED 電光掲示板**：ニュースの見出しが右から左へ流れます（政府広報オンラインの新着か、最近の地震（気象庁）を選べます）
- 夜間（初期値 23 時〜7 時）は画面を暗くします
- Wi-Fi は本体が出す Wi-Fi「NixieClock-Setup」につないで、スマホから設定できます

ダウンロード：[Releases](../../releases) の `NixieClock-<版>.bin`

## 対応機種

| 項目 | 内容 |
|------|------|
| 製品 | Smart Weather Clock（SD Pro） |
| マイコン | ESP8266（フラッシュ 4MB） |
| 画面 | ST7789 240×240 |

ほかの機種には書き込まないでください。ピン配置が違うと画面が映りません。

## 書き込み方

**自己責任でお願いします。** 書き込みに失敗すると、分解して USB シリアルから書き直す必要があるかもしれません。

### 元のファームから（初回）

1. 時計の IP アドレスを調べます（ルーターの接続一覧など）。
2. パソコンから元のファームの更新機能に送ります。

   ```bash
   curl -F "update=@NixieClock-1.6.4.bin" http://<時計のIP>/update_ota
   ```

   元のファームが書き込める大きさは約 500KB までです。このファームは約 460KB です。
3. 10 秒ほどで再起動します。家の Wi-Fi はまだ知らないので、次の「最初の設定」に進みます。

### このファームから（2 回目以降）

1. ブラウザで `http://<時計のIP>/update` を開きます。時計の IP アドレスは、時計の画面の一番上に出ています。
2. ユーザー名 `admin`、パスワードは Wi-Fi 設定のパスワード（初期値 `password`）でログインします。
3. 「Firmware」の欄で .bin ファイルを選び、「Update Firmware」を押します。1〜2 分で再起動します。

<img src="docs/images/05_update.png" width="360" alt="ファーム更新の画面">

## 通信について

- 時刻：NTP（`ntp.nict.jp`、`pool.ntp.org`）。日本時間で表示します。
- 日付の画像と電光掲示板の文字（政府広報オンライン・気象庁の情報を、サーバーが 1 時間に 1 回取りに行った分。出典を表示します）：`http://api.hasami.uk/clock/` から取ります（日付は毎日 0 時、ニュースは 10 分ごと）。
  時計には日本語フォントが無いので、サーバーが文字を点の画像にして返します。
  ESP8266 はメモリが少なく HTTPS では余裕がないため、HTTP で取ります。送るのは日付と取得元の種類だけで、個人の情報は送りません。
- このサーバーは個人で動かしているもので、予告なく止まったり変わったりすることがあります。止まると日付は英字（`10/5 MON`）になり、ニュースは流れません。

## うまく動かないとき

- **画面が真っ暗**：設定の「バックライト反転」を切り替えてください。
- **起動直後に 3 回続けて再起動した**：「安全モード」になり、画面を使わず Wi-Fi とファーム更新だけ動きます。`/update` から書き直してください。
- **元のファームに戻したい**：[JUZIPi-tech/SD_PRO](https://github.com/JUZIPi-tech/SD_PRO) の .bin を `/update` から書き込みます。
  元のファームのライセンス（リマインダー機能など）は、販売元での再発行が必要になるかもしれません。
